# MC6809 SBC1

Este modelo não acrescenta nada de significativo. As diferenças né que não usa o MC68B09P, mas sim o MC6805P, e por isso tem que usar um cristal com metade da frequencia 3.6864MHz (com condenadores de 24p e não de 15p ou 18p), e usa uma ROM de 64K (porque são as que tenho mais).

Foi feito para ter uma base funcional inicial, para começar a modificar. Uma das coisas que quero fazer  na proxima versão (SBC2)é um melhor decoding do MC68B50.
